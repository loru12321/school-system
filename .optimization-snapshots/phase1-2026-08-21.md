## Optimizations Implemented

### 1. Resource Hints for Critical Assets
**Priority**: High | **Complexity**: Low | **Risk**: Low

**Expected Impact**:

- Boot runtime parsing starts during HTML parse
- DNS resolution happens in parallel with page load

### 2. Icon Font Display Strategy
**Priority**: High | **Complexity**: Low | **Risk**: Low

Changed Tabler icons font loading:
- Added `font-display: swap` to `@font-face` rule in `subset-tabler-icons.mjs`
- Icons now show fallback text immediately, swap in when font loads

**Expected Impact**: Eliminates FOIT (Flash of Invisible Text) for icon font

### 3. Icon Subset Build Cache
**Priority**: Low | **Complexity**: Low | **Risk**: Low

Added smart cache check in `subset-tabler-icons.mjs`:
- Tracks icon usage hash in `.icon-subset-cache`
- Skips font regeneration when icon usage unchanged
- Cache file: `public/assets/fonts/tabler-icons/.icon-subset-cache`

**Expected Impact**: ~2-5 seconds saved on builds with no icon changes (90%+ of builds)

**Priority**: Medium | **Complexity**: Low | **Risk**: None

**Expected Impact**: Build size metrics visible in console output
