- **Preserved**: keyframes, font-face, CSS variables
- **Rejected tracking**: Enabled for audit trail

### Build Pipeline Order (Critical)
1. Group 1 (parallel): sync-public-assets + dedupe-dist-css
2. Group 2 (parallel): prune-dist-assets + optimize-dist-html
3. **purge-unused-css.mjs** (must run before inlining)
4. inline-scripts.mjs (inlines CSS into HTML)
5. optimize-images.mjs
6. precompress-assets.mjs

**Why order matters**: CSS purging requires separate CSS file. Once inlined into HTML, the CSS file reference is lost.
