## Cache Strategy

### Runtime Assets (stale-while-revalidate)
- First visit: Network fetch + cache
- Repeat visits: Instant cache serve + background update
- Always fresh on next visit
- Zero wait time for cached users

### Static Assets (cache-first)
- Fonts, icons, images
- Immutable hashed assets
- 1-year cache TTL

### API Responses (network-first with fallback)
- Health endpoint cached
- Bounded system-data queries cached
- Offline fallback support
