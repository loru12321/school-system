# 角色化使用教程视频脚本（复用拾修设备簿教程管线）

借鉴 `space-ledger/tutorial-video` 的「脚本化分镜 + Playwright 录屏 + TTS 配音 + FFmpeg 合成章节/字幕」思路，本目录提供澄见成绩分析系统的三套高频角色教程分镜脚本（见 [scripts.json](scripts.json)）：

1. **班主任使用教程**（约 2 分钟）：登录选届 → 班级成绩单与边缘生 → 培优建档 A4 导出/打印 → 互助分组。
2. **任课教师使用教程**（约 2 分钟）：登录选届 → 教师教学画像与乡镇排名 → 学科均衡与偏科潜力 → 提交任教班级/学科变更申请。
3. **教务管理员使用教程**（约 3 分钟）：新学年 9/1 准备清单 → 考务系统 Excel 一键导入（14 所乡镇校名自动归一）→ 兼容拾修设备簿名册导入 → 质量分析会 PPT/10表手册导出 → 危险操作区与云端同步。

> 说明：本目录仅保留纯文本分镜配置，不向主站 `dist/` 或 `lt.html` 引入任何视频/音频体积。录制时可直接复用本机 `playwright` 与 `ffmpeg` 按 `scripts.json` 分镜生成 MP4 与 `.srt` 字幕。
